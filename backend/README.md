# Booking System Backend

This backend is the initial foundation for the modular monolith described in the engineering specification. It establishes the required NestJS bootstrap, validation/error plumbing, and health endpoint foundation without implementing any business or persistence features yet.

## Current scope

- NestJS application bootstrap
- health endpoint and API version prefix
- environment configuration template
- modules organized around domain responsibilities

## Notes

- Domain data access and business logic remain intentionally unimplemented until the relevant phase.
- The project is still in the foundational phase and should be extended one phase at a time.
