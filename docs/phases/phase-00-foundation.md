# Phase 0 — Project Foundation

## Purpose
This phase establishes the initial backend and frontend foundation for the booking system without implementing business or domain features.

## Included
- NestJS backend bootstrap
- Next.js frontend bootstrap
- API version prefix and health endpoint
- validation and error-handling foundation
- environment examples
- minimal tests for app startup and health checks

## Excluded
- Prisma schema and migrations
- authentication
- organizations
- Bookables
- availability
- reservations
- payments
- access codes
- onboarding or dashboard functionality

## Notes
This document records the implementation boundary for the foundation phase only.
